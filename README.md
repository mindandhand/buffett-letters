1977—2024财年48篇完整中文译文、英文原文与中英对照，提供 Markdown 在线阅读和 Word 下载。另完成2025—2026年7份补充资料的全文翻译与原文整理。合计55份资料，提供中文、英文、中英对照各55份 Markdown 与 Word，共165份 Word。

[年度目录](#年度目录财年) · [2025—2026年补充资料](#20252026年补充资料) · [总体审查报告](校对记录/总体审查报告.md)

补充资料覆盖本项目登记的股东寄语、慈善说明与交接背景资料，并非这两年全部公司公告。年度信用财年编号：2025年发布的巴菲特年度信归入2024财年；2026年发布的2025财年年度信由阿贝尔署名。核查日为2026年11月27日，未收录尚未公布的2026财年年度信。

## 阅读入口

- [中文版](中文版)：完整中文译文，保留公司名称、股票代码和必要脚注。
- [英文版](英文版)：根据原始资料提取的英文全文，附必要的原件图片。
- [中英对照版](中英对照版)：早年按段落组、后期按原文PDF页交替排列英文和中文。
- [原始资料](原始资料)：原始HTML和PDF文件。
- [校对记录](校对记录/总体审查报告.md)：总体审查、原文异文与逐年校记。

Markdown 与 Word 放在同一个目录，年度信用财年命名，补充资料用发布日期和标题命名。所有Word由对应Markdown生成，正文、表格与图片来自同一份内容。

三套Word已全部生成，并完成正文一致性检查、批量渲染及逐页机器检查；代表页面作了视觉抽检，详见[Word生成检查](校对记录/Word生成检查.md)。

## 获取文件

点击表中的“阅读”可在线查看全文；点击“Word”进入文件页后选择下载。需要完整项目时，在GitHub仓库首页选择 **Code → Download ZIP**，或使用：

```sh
git clone https://github.com/mindandhand/buffett-letters.git
```

## 重新生成

运行环境：Python 3，安装`工具/requirements.txt`中的依赖。已有文件可直接阅读，无需运行工具。只核验当前版本时执行：

```sh
python3 工具/check_project.py
```

修改中文或英文Markdown后，先根据`校对记录/对齐数据.json`更新对应的对照段落，再运行`工具/build_bilingual.py`和Word生成工具。补充资料使用`校对记录/补充对齐数据.json`与`工具/build_supplements.py`重生成三套Markdown，使用`工具/build_word.py --supplements`生成Word。重生成工具不会自动翻译或猜测段落对应关系。Word重生成后需重新渲染、检查排版并更新对应哈希记录，才能通过完整校验，详见[工具说明](工具/README.md)。
