# 术语表

| 英文 | 中文 |
| --- | --- |
| intrinsic value | 内在价值 |
| book value | 账面价值 |
| float | 浮存金 |
| underwriting profit or loss | 承保利润或亏损 |
| look-through earnings | 穿透利润或穿透盈余 |
| goodwill | 商誉 |
| economic goodwill | 经济商誉 |
| purchase-accounting adjustments | 购买会计调整或收购会计调整 |

既有译稿中个别公司中文译名存在历史用法差异，英文正式名称用于辨识同一企业。数字及比较口径按各年度原件保留。
